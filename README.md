# LIB 業務自動化ツール（GAS）

スプレッドシートを管理画面にして、**毎回手作業でやっている定型業務**をまとめて自動化する Google Apps Script プロジェクトです。

| 自動化するもの | 入力 | 出力 |
|----------------|------|------|
| **GBP投稿の下書き** | リール動画 / 写真 + メモ | 投稿文（シート）＋ 写真（Driveフォルダ） |
| **請求書** | 請求先・明細（1行入力） | 請求書ドキュメント ＋ PDF（Driveフォルダ） |
| **台本** | 企画・テーマ + メモ | 決まった型の台本ドキュメント（Driveフォルダ） |

---

## 1. Googleビジネスプロフィール 投稿・写真の自動下書き

**Googleビジネスプロフィール（GBP）の「最新情報」投稿文と写真を自動で下書き準備**します。

- リール動画 → **Notta(+Zapier)で文字起こし** → Claude で投稿文に要約（**パターンA**）
- 写真 + メモ → Claude で投稿文に整形（**パターンB**）
- 完成した投稿文はスプレッドシートに、写真は Drive の「投稿準備済」フォルダに集約

> ⚠️ **このツールは「下書き準備」までを自動化します。** GBP への最終投稿は人が確認してから行う運用です（GBP の Business Profile API は利用申請・審査が必要なため、まずは審査不要のこの形から始められます）。

詳しい全体設計・運用フローは [`docs/SETUP.md`](docs/SETUP.md) を参照してください。

## できること

| 機能 | 内容 |
|------|------|
| 文字起こし | Notta(+Zapier) でリール動画を文字に変換 → 結果をシート/Driveで受け取り |
| 文章生成 | 文字起こし結果・メモ・写真情報から GBP 投稿文を Claude が作成 |
| 写真整理 | Drive / Dropbox から写真を取得し「投稿準備済」フォルダへ |
| 進捗管理 | スプレッドシートで `下書き作成中 → 確認待ち → 投稿済` を管理 |

## 2. 請求書の自動作成

「請求書」シートに1行入力して実行するだけで、**請求書ドキュメントとPDFを自動生成**します。

- 請求番号（`INV-202609-001`）… 月ごとに自動採番
- 消費税・小計・合計 … 自動計算（税率・端数処理は設定で変更可）
- 支払期限 … 空欄なら翌月末を自動計算
- テンプレート（Googleドキュメント）も**メニューから自動生成**できます。ロゴや文言はあとから自由に編集可能

```
請求先: 株式会社サンプル / 件名: 6月分 制作費
明細:  リール動画制作,3,30000
      撮影ディレクション,50000
   ↓  ［請求書］→［請求書を作成］
Driveの「請求書」フォルダに  INV-202609-001_株式会社サンプル.pdf
```

> ⚠️ 金額の取り違えを防ぐため、読み取れない明細は**推測せずエラー**にします（`docs/SETUP.md` 参照）。

---

## 3. 台本の自動作成

テーマとメモを入れるだけで、Claudeが構成を考え、**毎回同じフォーマットのドキュメント**を作ります。

生成される内容: タイトル案 / 冒頭フック / **構成表（秒数・映像・セリフ・テロップ）** / 締めCTA / ハッシュタグ / 撮影メモ

---

## 構成ファイル

```
gas/
  appsscript.json     … マニフェスト（権限スコープ）
  Config.gs           … 設定・APIキー（スクリプトプロパティ）
  Menu.gs             … スプレッドシートのカスタムメニュー
  Main.gs             … GBP投稿: メイン処理
  SheetService.gs     … シート読み書き
  DriveService.gs     … Google Drive のファイル取得・整理
  DropboxService.gs   … Dropbox のファイル取得
  Transcribe.gs       … Nottaの文字起こし結果を受け取る（シートE列 / Driveの.txt）
  Claude.gs           … Claude API 呼び出し（投稿文・台本の生成）
  DocService.gs       … ドキュメント／Driveフォルダの共通処理
  Invoice.gs          … 請求書の作成
  InvoiceTemplate.gs  … 請求書テンプレートの自動生成
  Scenario.gs         … 台本の作成
docs/
  SETUP.md            … 導入手順・全体設計
tests/
  run.js              … 金額計算まわりの自動テスト（node tests/run.js）
```

## クイックスタート

1. [clasp](https://github.com/google/clasp) を使うか、Apps Script エディタに `gas/` の中身を貼り付け
2. スプレッドシートに「投稿管理」シートを用意（列は `docs/SETUP.md` 参照）
3. スクリプトプロパティに API キーを登録（`Config.gs` 参照）
4. スプレッドシートを再読み込みすると **［GBP自動化］［請求書］［台本］** のメニューが出ます
5. 請求書・台本は各メニューの **［シートを準備］** から始めてください

## テスト

```
node tests/run.js
```

請求金額の計算ロジック（明細のパース・消費税の端数処理・請求番号の採番）を検証します。
