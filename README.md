# Googleビジネスプロフィール 投稿・写真 自動下書きツール（GAS）

スプレッドシートを管理画面にして、**Googleビジネスプロフィール（GBP）の「最新情報」投稿文と写真を自動で下書き準備**するための Google Apps Script プロジェクトです。

- リール動画 → **Notta(+Zapier)で文字起こし** → Claude で投稿文に要約（**パターンA**）
- 写真 + メモ → Claude で投稿文に整形（**パターンB**）
- 完成した投稿文はスプレッドシートに、写真は Drive の「投稿準備済」フォルダに集約

> ⚠️ **このツールは「下書き準備」までを自動化します。** GBP への最終投稿は人が確認してから行う運用です（GBP の Business Profile API は利用申請・審査が必要なため、まずは審査不要のこの形から始められます）。

詳しい全体設計・運用フローは [`docs/SETUP.md`](docs/SETUP.md) を参照してください。

## できること

| 機能 | 内容 |
|------|------|
| 文字起こし | Notta(+Zapier) でリール動画を文字に変換 → 結果をシート/Driveで受け取り |
| 文章生成 | 文字起こし結果・メモ・写真情報から GBP 投稿文を Claude が作成 |
| 写真整理 | Drive / Dropbox から写真を取得し「投稿準備済」フォルダへ |
| 進捗管理 | スプレッドシートで `下書き作成中 → 確認待ち → 投稿済` を管理 |

## 構成ファイル

```
gas/
  appsscript.json   … マニフェスト（権限スコープ）
  Config.gs         … 設定・APIキー（スクリプトプロパティ）
  Menu.gs           … スプレッドシートのカスタムメニュー
  Main.gs           … メイン処理（行を走査して下書きを作る）
  SheetService.gs   … シート読み書き
  DriveService.gs   … Google Drive のファイル取得・整理
  DropboxService.gs … Dropbox のファイル取得
  Transcribe.gs     … Nottaの文字起こし結果を受け取る（シートE列 / Driveの.txt）
  Claude.gs         … Claude API 呼び出し（投稿文生成）
docs/
  SETUP.md          … 導入手順・全体設計
```

## クイックスタート

1. [clasp](https://github.com/google/clasp) を使うか、Apps Script エディタに `gas/` の中身を貼り付け
2. スプレッドシートに「投稿管理」シートを用意（列は `docs/SETUP.md` 参照）
3. スクリプトプロパティに API キーを登録（`Config.gs` 参照）
4. シートのメニュー **［GBP自動化］→［下書きを作成］** を実行

# SNS分析・レポートアプリ「ORANGE INSIGHT」by LIB creation（`app/`）

Instagram・Meta広告（Meta Business Suite）・TikTok・TikTokプロモート・YouTubeショートの数字をCSVで取り込み、分析して月次レポートを作るアプリです。**採用版 / 集客版** を画面右上で切り替えられます（ファネルの言葉が「エントリー→面接→採用」と「問い合わせ→来店・商談→成約」で変わります）。

`app/index.html` をブラウザで開くだけで動きます（サーバー・インストール不要）。データはそのブラウザに保存されます。

| 画面 | できること |
|------|-----------|
| ダッシュボード | 今月のKPI、採用/集客ファネル、5つの移行率（目標との差）、推移グラフ、媒体横断の合計 |
| クライアント一覧 / 詳細・ヒアリング | 検索・絞り込み、会社情報、ヒアリングシート、関連ファイルのリンク |
| 月次データ入力 | 媒体ごとの実績、フォロワー属性（男女・年齢・地域）、レポートのコメント |
| CSVインポート | 各媒体の書き出しCSVを入れるだけ（複数ファイル可）。媒体・月・項目を自動で読み取り、日別→月別に集計。確認して「反映する」を押すだけ。ルールで判断できない列はClaudeが判定（claude.ai上で開いたとき） |
| コンテンツ分析 | その月に上げたリール・フィード投稿・ストーリーズを一覧表示。閲覧数・リーチ・いいね・保存・ENG率などで高い順に並び替え。Meta Business Suite の「コンテンツ」CSVを取り込み、サムネイル画像も追加できる |
| フォロワー分析 / 媒体横断分析 / 期間比較 | 媒体・期間・クライアントをまたいだ比較、広告のCPA・CPC・CTR |
| 成果レポート | 印刷・PDF保存できる月次レポート（総評・展望・次の一手の自動提案つき） |
| 制作管理 | タスク一覧とガントチャート |
| 目標設定（コミット） | 移行率の目標に加え、毎月のKPI目標件数（エントリー・面接・採用・LINE登録など）を設定。ダッシュボードとレポートでコミット率（実績÷目標）、総合コミット率、今月の着地見込みを表示 |
| 目標設定 / 編集者管理 / デザイン設定 | 移行率の目標、編集者の登録、テーマ・色・書体・ロゴ |

> 初回はサンプルデータ（株式会社オーロラほか）が入っています。ダッシュボード上部の「サンプルをすべて削除」で消せます。
> 各媒体のAPIへの自動連携は未実装です（「アカウント連携」画面に必要なものを記載）。それまではCSVで取り込みます。
