## エディタで設定が必要（API では変更できない）

### 1. 言語・地域 ★未設定

現在 英語 / アメリカ / New York / USD のまま。ダッシュボードの
「設定 → 言語と地域」で以下に変更する。

| 項目 | 設定値 |
|------|--------|
| 言語 | 日本語 |
| 地域 | 日本 |
| タイムゾーン | Asia/Tokyo |
| 通貨 | JPY（決済は使わないが表示のため） |

### 2. サイトテーマカラー

エディタの ［サイトデザイン］→［カラーパレット］に登録する。

| 用途 | HEX | 使いどころ |
|------|-----|-----------|
| ベース | `#FFFFFF` | 標準の背景 |
| ベース2 | `#FAF8F5` | 交互に挟むセクション背景 |
| プレースホルダー | `#F2EEE9` | 写真枠（撮影までの仮） |
| 墨 | `#2B2523` | 見出し・強い本文 |
| 本文グレー | `#6B615C` | 本文 |
| 補助グレー | `#A2958B` | ラベル・注記・［ ］の未確定表示 |
| 罫線 | `#E8E2DA` | 区切り線・枠線 |
| 罫線（薄） | `#EFEAE3` | ヘッダー下・カード枠 |
| **差し色** | `#6B2737` | **ワインレッド。花の線画・見出しの一語・数字・LINEボタン・同意書ステップの枠のみ** |

差し色の割合を増やさないこと。ベタ塗りの面には使わない。

### 3. フォント

［サイトデザイン］→［テキストテーマ］。日本語フォントを出すには
［デザイン］→［フォント］→［言語サポート］で **日本語を ON** にする必要がある。

| 役割 | フォント | ウエイト |
|------|---------|---------|
| 見出し・本文 | **Noto Sans JP** | 300 / 400 / 500 / 700 |
| ロゴ「AtelierForcal」 | **Cormorant Garamond** | 400 |

## 注意

- **Velo は有効化しない。** 有効にすると納品後に店舗様が触れなくなる。
- 同意書ページのフォームには **署名欄（プレミアム機能）** を使う。
  無料プランのままでは動かないため、プラン確定後に設定する。
- 納品時は権限を **「コンテンツ編集のみ」** に絞る。
  写真差し替えでレイアウトが崩れないようにするため。
