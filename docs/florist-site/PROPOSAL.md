# アトリエフォルカル様 サイトリニューアル 要件・構成案（Wix）

- 現行サイト: https://www.atelierforcal.com/
- リニューアル参考: https://www.kannax.com/
- 制作環境: Wix（ノーコードで納品・以後は店舗様が自分で編集できること）
- 写真: サイト完成後に撮影 → 差し替え運用

> 注記: 本ドキュメント作成環境からは上記2サイトへ直接アクセスできなかったため、
> サイト構成の把握は検索結果ベース。実装着手前に実サイトを見て確定する。

## 決定事項（2026-09-01）

- **制作場所**: 店舗様の Wix アカウントに**共同管理者として招待**してもらい、そこで制作。
  → サイト移管は不要。ドメイン・既存プランもそのまま使える。
- **オンライン決済**: **なし**。申込 → 見積り → 振込／対面 の運用。
  → Wix ストア／予約は入れない。フォーム中心のシンプル構成。
- **誓約書**: 専用ページを1枚作り、TOP をはじめ各所からリンクする方式。

## 0. 結論

**3つの特別要件（誓約書・公式LINE・ノーコード納品）はすべて Wix の標準機能で実現可能。**
カスタムコード（Velo）は使わない前提で設計する。Velo を入れると納品後に
店舗様が触れなくなり、「ノーコードで渡す」という前提が崩れるため。

## 1. 業態の理解（設計の前提）

アトリエフォルカル様は **持ち込みの生花をプリザーブド／保存加工** するお店。
プロポーズ・ウェディングブーケなど「二度と手に入らない、思い出の花」を預かる business。

参考の Kannax 社は同業（アフターブーケ）の最大手。つまりリニューアルの狙いは
**「花屋のサイト」ではなく「大切な花をお預かりする加工サービスのサイト」** に寄せること。

この業態理解が、そのまま誓約書が必要な理由になる:

- 生花は個体差があり、加工後の色・形の変化を完全には保証できない
- 加工すると元の状態には戻せない（不可逆）
- 唯一無二の品を預かるため、万一の破損時に金銭賠償で代替できない
- 花の鮮度によって仕上がりが左右される（持ち込みまでの日数）

→ 誓約書は「守りの書類」であると同時に、**丁寧に説明する姿勢＝信頼の演出**にもなる。
　注文フローの中で隠さず前面に出す設計にする。

## 2. 特別要件の実現方法

### 2-1. 誓約書

決済を載せないため、**「誓約書ページ」を1枚作り、TOP・ご注文の流れ・LINE からリンクする**構成にする。

#### ひとつだけ確認したいこと

「TOP にリンクが貼れればいい」との事だが、当初のご要望は「注文前に誓約書を**取りたい**」だった。
リンクを貼るだけだと**同意を"見せる"ことはできても"取る"ことはできない**（読んだ証拠が残らない）。

→ **リンク先のページに、誓約書の本文と署名フォームを両方置く**のを推奨。
　 手間はほぼ変わらず、「リンクを貼るだけ」の要望も満たしつつ、署名記録も残る。

#### 実装の2択

| | **A: Wix フォーム（署名欄）** ★推奨 | **B: Wix 受付フォームアプリ** |
|---|---|---|
| 中身 | 通常ページに誓約本文＋必須チェック＋署名欄 | 免責同意書用の専用アプリ。署名・条件分岐など |
| 見せ方 | **普通のページ**（`/誓約書` 等）。リンクを貼るだけ | 予約フローに組み込む or **リンクを配布**する形 |
| 店舗様の編集 | エディタ上で本文を直接編集できる | アプリの管理画面から編集 |
| 記録 | ダッシュボードに署名画像つきで保存 | 顧客ごとに紐づけて保存。再提出の頻度設定も可 |
| 向き | 今回のように予約導線がない構成 | 予約（Wix ブッキング）と併用する構成 |

**A を推奨する理由**: 今回は予約機能を入れないため、受付フォームアプリは
「リンクを配布する」使い方になり、サイト内に自然に置きにくい。
通常ページなら TOP からもフローからも普通にリンクでき、店舗様が文面を直接直せる。

**A の作り:**

1. 「誓約書・お申し込み」ページを作る
2. 誓約事項の本文を配置（色変化・不可逆・納期・免責 など）
3. 必須の同意チェックボックス（項目を分けると意思確認として強い）
4. **署名欄**（Wix フォームのプレミアム機能。必須設定に）
5. 送信 → ダッシュボードに署名画像つきで保存 ＋ 店舗宛に通知メール
6. 自動返信メールでお客様にも控え（同意内容・日時）を送る

**注意点:** Wix 側も「電子署名の法的効力は国ごとに要件が異なる」と明記している。
高額案件はお渡し時に紙の署名も併用する運用を提案する。最終判断は店舗様。

**誓約書に盛り込む項目（叩き台）:**

- 仕上がりの色・形は元の花と変わる場合があること
- 一度加工すると元の状態には戻せないこと
- 花の状態・鮮度により仕上がりが左右されること
- 自然素材のため経年変化（退色等）が起こること
- 万一の破損時の補償範囲
- 納期の目安と変動の可能性
- キャンセル・返品の可否
- 制作事例としての写真掲載の可否（別項目で任意選択に）

### 2-2. 公式LINE の設置

Wix エディタの `追加 → ソーシャル → LINE` で友だち追加ボタンを配置し、
公式LINEのURL（`https://lin.ee/xxxx`）を設定するだけ。ノーコード。
オリジナル画像にリンクを貼る形でもよい。

**設置する場所（導線設計）:**

- 全ページ追従のフローティングボタン（右下）
- ヘッダーのCTA
- フッター
- 「ご注文の流れ」ページの「まず相談する」ステップ

**導線の考え方:**
```
      ＜気軽な入口＞                 ＜正式な受注＞
LINEで相談・写真送付・見積り  →  申込フォーム（誓約書＋署名）  →  お預かり
```
LINE = 相談窓口、フォーム = 正式受注。この役割分担を明確にする。
誓約書をLINEでやり取りしようとすると記録が散らかるので、必ずフォームに寄せる。

### 2-3. ノーコード納品

**設計方針: Velo（カスタムコード）は使わない。標準アプリ・標準機能のみで組む。**

| やりたいこと | 使う標準機能 |
|---|---|
| 誓約書＋署名 | Wix フォーム（署名フィールド） |
| 商品・価格 | CMS コレクション＋リピーター（決済なしのため料金表として表示） |
| ギャラリー／実績 | Wix Pro ギャラリー |
| よくある質問 | FAQ アプリ（アコーディオン） |
| お客様の声 | CMS コレクション（店舗様が行追加で更新できる） |
| ブログ・お知らせ | Wix ブログ |
| LINE | ソーシャルボタン |
| 自動返信メール | Wix オートメーション |

**エディタの選択:** 納品後に店舗様ご自身が触ることが前提なので、
**Wix（クラシックエディタ）を推奨**。Wix Studio は表現力は高いが編集画面が
専門的で、非エンジニアの引き継ぎには向かない。

**更新しやすさの担保（納品物）:**
- 更新マニュアル（写真の差し替え・価格変更・お知らせ追加の3点だけでも）
- テキストは可能な限り CMS 化しておく（レイアウトを壊さず文言だけ変えられる）

## 3. サイト構成案（Kannax を参考に）

```
TOP
 ├ 世界観のヒーロー（加工後の作品）
 ├ ビフォー／アフター（ここが一番の武器）
 ├ 3つのシーン（プロポーズ／ウェディング／記念日）
 ├ 選ばれる理由
 └ CTA（LINEで相談 ／ お申し込み）

保存加工について      … 何ができるのか、どう仕上がるのか
商品ラインナップ・料金 … 額装／ケース／ドーム 等 ＋ 価格表
ご注文の流れ          … ★誓約書のステップを明示して隠さない
花の送り方・持ち込み方 … 「いつまでに」を最重要情報として大きく
ギャラリー・制作事例
お客様の声
よくある質問          … 色変化・納期・返却不可 など（誓約書と対応させる）
店舗案内・アクセス
会社概要
お申し込みフォーム    … ★誓約書＋署名
ブログ／お知らせ
プライバシーポリシー（※決済なしのため特商法表記は原則不要）
```

### 「ご注文の流れ」の設計（要件の中心）

```
1. LINE or フォームで相談
2. 加工内容・お見積りのご案内
3. ★お申し込みフォームで誓約書に同意・署名
4. 花のお預かり（持ち込み／配送）
5. 加工（納期の目安を明示）
6. お渡し・発送
```
3 を飛ばして 4 に進めない、という運用ルールをサイト上でも明文化する。

## 4. 写真について

「サイト完成後に撮影 → 差し替え」で問題なし。仮画像で組んでおき、
Wix のメディアマネージャーで同じ枠に差し替えれば崩れない。

**ただし撮影前に決めておくべきこと:**
- 各枠の**縦横比**（後から比率の違う写真を入れるとトリミングで悩む）
- ヒーロー画像は横長・余白多め（テキストを重ねるため）
- ビフォー／アフターは**同じ画角・同じ背景**で撮る（比較にならないと意味がない）

→ 着手時に「撮影指示書（必要カット一覧＋比率＋構図メモ）」を先に納品するのがおすすめ。

## 5. 制作環境（決定済み）

店舗様の Wix アカウントに**共同管理者（Contributor）として招待**してもらう方式。

- サイト移管の作業が不要。ドメイン・既存プランもそのまま
- 現行サイトが既に Wix なら、**既存サイトのコピーを作って作業 → 完成後に差し替え**が可能
- 公開前は「準備中」ページやパスワード保護で見えないようにできる

**必要な手続き:** 店舗様に Wix ダッシュボードの「ロールと権限」から
制作担当のメールアドレスを招待していただく。権限は「ウェブサイトマネージャー」相当で足りる。

## 6. 確認が必要な事項

**決定済み:** Wix アカウント（招待方式）／オンライン決済（なし）

**未確認:**

1. **現行サイトのプラットフォーム**: Wix か、別サービス（Jimdo 等）か
   → Wix なら既存サイトのコピーから作業できる
2. **ドメイン `atelierforcal.com` の管理場所**: Wix か、外部レジストラか
3. **Wix のプラン**: フォームの署名欄は有料機能のため、現プランの確認が必要
4. **誓約書の文面**: 既存のものがあるか（現状は紙・口頭？）。なければ上記の叩き台から作成
5. **公式LINE**: 開設済みか。友だち追加URL（`lin.ee/xxxx`）
6. **共同管理者の招待**: 招待先メールアドレスの確定
