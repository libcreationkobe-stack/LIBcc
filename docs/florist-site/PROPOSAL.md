# アトリエフォルカル様 サイトリニューアル 要件・構成案（Wix）

- 現行サイト: https://www.atelierforcal.com/
- リニューアル参考: https://www.kannax.com/
- 制作環境: Wix（ノーコードで納品・以後は店舗様が自分で編集できること）
- 写真: サイト完成後に撮影 → 差し替え運用

## 決定事項（2026-09-01）

- **制作場所**: **LIB アカウントで新規サイトを制作 → 完成後に店舗様へ移管**（ルートB）。
  → 店舗様の操作待ちがなく、すぐ着手できる。移管の承認は3日以内にもらえる前提。
  → 決済を載せないため、移管の最大の制約（Wix Payments は移管不可）に当たらない。
- **ドメイン**: `atelierforcal.com` は**店舗様の Wix アカウント内**で管理。
  → 移管後、店舗様が「ドメイン → 別のサイトに割り当て」で新サイトに付け替えれば公開完了。
- **オンライン決済**: **なし**。申込 → 見積り → 振込／対面 の運用。
  → Wix ストア／予約は入れない。フォーム中心のシンプル構成。
- **誓約書**: 専用ページを1枚作り、TOP をはじめ各所からリンクする方式。
- **制作ツール**: **Wix Studio**（テンプレートから）。
  - ⚠️ **Studio 製サイトには Studio プランが必要。** 通常の Wix プレミアムプランは
    Wix エディタ製サイト専用のため、店舗様の既存プランは流用できず
    アップグレードが必要（残日数分は充当される）。**月額が上がる可能性があるため要確認。**
  - ⭕️ Studio 製サイトも通常の Wix アカウントに移管でき、
    新オーナーは Wix Studio に切り替えなくても編集できる。
  - ⭕️ Studio は権限を**「コンテンツ編集のみ」**（テキスト・リンク・画像のみ可、
    レイアウト／デザインは不可）に絞れる。写真差し替え運用と相性が良い。
  - ⚠️ レイヤーのロック機能は未提供のため、許可範囲内でのズレは起こりうる。
  - ⚠️ Studio エディタは通常の Wix と操作の考え方が異なる。簡易マニュアルは必須。

## 0. 結論

**3つの特別要件（誓約書・公式LINE・ノーコード納品）はすべて Wix の標準機能で実現可能。**
カスタムコード（Velo）は使わない前提で設計する。Velo を入れると納品後に
店舗様が触れなくなり、「ノーコードで渡す」という前提が崩れるため。

## 1. 業態の理解（設計の前提）

アトリエフォルカル様は **持ち込みの生花をプリザーブド／保存加工** するお店。
プロポーズ・ウェディングブーケなど「二度と手に入らない、思い出の花」を預かる business。

参考の Kannax 社は同業（アフターブーケ）の最大手。つまりリニューアルの狙いは
**「花屋のサイト」ではなく「大切な花をお預かりする加工サービスのサイト」** に寄せること。

この業態理解が、そのまま誓約書が必要な理由になる:

- 生花は個体差があり、加工後の色・形の変化を完全には保証できない
- 加工すると元の状態には戻せない（不可逆）
- 唯一無二の品を預かるため、万一の破損時に金銭賠償で代替できない
- 花の鮮度によって仕上がりが左右される（持ち込みまでの日数）

→ 誓約書は「守りの書類」であると同時に、**丁寧に説明する姿勢＝信頼の演出**にもなる。
　注文フローの中で隠さず前面に出す設計にする。

## 2. 特別要件の実現方法

### 2-1. 誓約書

決済を載せないため、**「誓約書ページ」を1枚作り、TOP・ご注文の流れ・LINE からリンクする**構成にする。

#### ひとつだけ確認したいこと

「TOP にリンクが貼れればいい」との事だが、当初のご要望は「注文前に誓約書を**取りたい**」だった。
リンクを貼るだけだと**同意を"見せる"ことはできても"取る"ことはできない**（読んだ証拠が残らない）。

→ **リンク先のページに、誓約書の本文と署名フォームを両方置く**のを推奨。
　 手間はほぼ変わらず、「リンクを貼るだけ」の要望も満たしつつ、署名記録も残る。

#### 実装の2択

| | **A: Wix フォーム（署名欄）** ★推奨 | **B: Wix 受付フォームアプリ** |
|---|---|---|
| 中身 | 通常ページに誓約本文＋必須チェック＋署名欄 | 免責同意書用の専用アプリ。署名・条件分岐など |
| 見せ方 | **普通のページ**（`/誓約書` 等）。リンクを貼るだけ | 予約フローに組み込む or **リンクを配布**する形 |
| 店舗様の編集 | エディタ上で本文を直接編集できる | アプリの管理画面から編集 |
| 記録 | ダッシュボードに署名画像つきで保存 | 顧客ごとに紐づけて保存。再提出の頻度設定も可 |
| 向き | 今回のように予約導線がない構成 | 予約（Wix ブッキング）と併用する構成 |

**A を推奨する理由**: 今回は予約機能を入れないため、受付フォームアプリは
「リンクを配布する」使い方になり、サイト内に自然に置きにくい。
通常ページなら TOP からもフローからも普通にリンクでき、店舗様が文面を直接直せる。

**A の作り:**

1. 「誓約書・お申し込み」ページを作る
2. 誓約事項の本文を配置（色変化・不可逆・納期・免責 など）
3. 必須の同意チェックボックス（項目を分けると意思確認として強い）
4. **署名欄**（Wix フォームのプレミアム機能。必須設定に）
5. 送信 → ダッシュボードに署名画像つきで保存 ＋ 店舗宛に通知メール
6. 自動返信メールでお客様にも控え（同意内容・日時）を送る

**注意点:** Wix 側も「電子署名の法的効力は国ごとに要件が異なる」と明記している。
高額案件はお渡し時に紙の署名も併用する運用を提案する。最終判断は店舗様。

**誓約書に盛り込む項目（叩き台）:**

- 仕上がりの色・形は元の花と変わる場合があること
- 一度加工すると元の状態には戻せないこと
- 花の状態・鮮度により仕上がりが左右されること
- 自然素材のため経年変化（退色等）が起こること
- 万一の破損時の補償範囲
- 納期の目安と変動の可能性
- キャンセル・返品の可否
- 制作事例としての写真掲載の可否（別項目で任意選択に）

### 2-2. 公式LINE の設置

公式LINE は**既に開設済み**（現行サイトのフッターにアイコンあり）。友だち追加URLをもらえば設置できる。

Wix の `追加 → ソーシャル → LINE` で友だち追加ボタンを配置し、
公式LINEのURL（`https://lin.ee/xxxx`）を設定するだけ。ノーコード。
オリジナル画像にリンクを貼る形でもよい。

**現行サイトの問題:** 受付は「公式LINEもしくはお電話」と**文章で書いてあるだけ**で、
LINEアイコンはフッターの隅にしかない。完全予約制でLINEが主要な受付窓口なのに、
導線として機能していない。リニューアルでは明確なボタンにする。

**設置する場所（導線設計）:**

- 全ページ追従のフローティングボタン（右下）
- ヘッダーのCTA
- フッター
- 「ご注文の流れ」ページの「まず相談する」ステップ

**導線の考え方:**
```
      ＜気軽な入口＞                 ＜正式な受注＞
LINEで相談・写真送付・見積り  →  申込フォーム（誓約書＋署名）  →  お預かり
```
LINE = 相談窓口、フォーム = 正式受注。この役割分担を明確にする。
誓約書をLINEでやり取りしようとすると記録が散らかるので、必ずフォームに寄せる。

### 2-3. ノーコード納品

**設計方針: Velo（カスタムコード）は使わない。標準アプリ・標準機能のみで組む。**

| やりたいこと | 使う標準機能 |
|---|---|
| 誓約書＋署名 | Wix フォーム（署名フィールド） |
| 商品・価格 | CMS コレクション＋リピーター（決済なしのため料金表として表示） |
| ギャラリー／実績 | Wix Pro ギャラリー |
| よくある質問 | FAQ アプリ（アコーディオン） |
| お客様の声 | CMS コレクション（店舗様が行追加で更新できる） |
| ブログ・お知らせ | Wix ブログ |
| LINE | ソーシャルボタン |
| 自動返信メール | Wix オートメーション |

**エディタの選択:** 納品後に店舗様ご自身が触ることが前提なので、
**Wix（クラシックエディタ）を推奨**。Wix Studio は表現力は高いが編集画面が
専門的で、非エンジニアの引き継ぎには向かない。

**更新しやすさの担保（納品物）:**
- 更新マニュアル（写真の差し替え・価格変更・お知らせ追加の3点だけでも）
- テキストは可能な限り CMS 化しておく（レイアウトを壊さず文言だけ変えられる）

## 4. 写真について

サイト完成後に撮影 → 差し替えで進める。仮画像で組んでおき、Wix のメディアマネージャーで
同じ枠に差し替えれば崩れない。Studio の「コンテンツ編集のみ」権限なら、
納品後も店舗様が安全に差し替えられる。

**撮影前に決めておくこと:**

- 各枠の**縦横比**（後から比率の違う写真を入れるとトリミングで詰む）
- ヒーロー画像は横長・余白多め（テキストを重ねるため）

**必要カット（撮影指示書の骨子）:**

| 用途 | 枚数 | 条件 |
|------|------|------|
| ヒーロー | 1〜2 | 横長。人物ありだと感情が乗る（花を抱える／作品を持つ手元） |
| **ビフォー／アフター** | 3組以上 | ★**同じ画角・同じ背景・同じ光**で撮る。違うと比較にならない |
| 作品ギャラリー | 8点以上 | 額装／ケース／ドーム など種類を散らす。**正方形で統一**すると並べやすい |
| ご注文の流れ | 4〜6 | 受付・お預かり・加工作業・お渡し。**作業風景は信頼に直結**する |
| 店内・外観 | 2〜3 | 初来店の不安を下げる |
| 店主 | 1 | 個人店の強み。顔が見えると預ける決断がしやすい |

**掲載許可について:** 現行サイトの作品写真は名入れ部分にモザイクがかかっている。
誓約書に「制作事例としての写真掲載の可否」を任意項目で入れておけば、
以後はモザイクなしで掲載できる作品が増える。運用改善として提案したい。

## 5. 制作環境と公開までの段取り（決定済み）

**ルートB: LIB アカウントで制作 → 移管**

```
1. LIB アカウントで新規サイト作成          … LIB
2. 構築（ページ・文言・フォーム・LINE）      … LIB
3. パスワード保護で公開し、店舗様が確認      … 店舗様
4. サイト移管を送信 → 3日以内に承認        … LIB → 店舗様
5. プレミアムプランを新サイトに割り当て      … 店舗様
6. ドメイン atelierforcal.com を新サイトへ  … 店舗様（Wix内なので数クリック）
7. 公開。旧サイトはバックアップとして残す
```

**注意点:**

- **署名欄はプレミアム機能。** 移管前に本番テストするには LIB 側で一時的にプランを
  当てる必要がある。プランごと移管もできるので、そちらの方が確実。
  プランを当てずに進める場合は、移管後に店舗様側で最終テストが必要。
- 移管の招待メールは**3日で失効**する。送信タイミングを事前に合わせる。
- ドメインは店舗様の Wix アカウント内にあるため、移管後に
  「ドメイン → 別のサイトに割り当て」で付け替えるだけ。DNS 作業は不要。
- 旧サイトは削除せず残す（切り戻し先として）。

## 6. 確認が必要な事項

**決定済み:** 制作＝ルートB（移管方式）／ドメイン＝店舗様の Wix アカウント内／
オンライン決済なし／制作ツール＝Wix Studio

**現行サイトから判明済み:** 完全予約制・木曜定休・納期4ヶ月〜4ヶ月半・予約割引の条件・
住所・TEL/FAX・公式LINE と Instagram の存在・現行は Wix

**未確認（優先度順）:**

1. **Studio プランの費用** ★金額の話なので最優先
   既存プレミアムプランからのアップグレード額を店舗様に確認・合意する
2. **コピーを書くための情報**（要ヒアリング）
   - 創業年 / 累計制作点数 ← Kannax の「39年」「70万個」に対抗する信頼材料
   - 加工技術の特徴（他店との違い）
   - **4ヶ月半かかる理由** ← 説明できれば納期が弱みから強みに変わる
   - 料金表
   - お客様の声（既存のものがあれば）
3. **誓約書の文面**: 既存のものがあるか（現状は紙・口頭？）。なければ叩き台から作成
4. **公式LINE の友だち追加URL**（`lin.ee/xxxx`）
5. **移管先メールアドレス**: 店舗様の Wix アカウントのメールアドレス
