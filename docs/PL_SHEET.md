# LIB経営管理シート（PL）に足す経営判断タブ

`gas/PlDashboard.gs` を「LIB経営管理」のApps Scriptに貼り、
`setupManagementSheets` を実行すると5つのタブができる。

既存のPL入力表には一切書き込まない。ラベルを頼りに値を引くので、
行を挿入しても月の列を足しても壊れない。

| タブ | 役割 |
|---|---|
| 設定 | 税率・目標・決算月・預金残高など。ここだけ触れば全部の計算が変わる |
| ダッシュボード | 今月の実績、確保すべき額、使っていい金額、危険信号 |
| 資金繰り予測 | 12ヶ月の残高推移。現金が尽きる月を先に見つける |
| 納税カレンダー | 決算月から逆算した、いつ何を払うか |
| 支払い予定 | 項目ごとの支払日を入れると、月内の支払いが日付順に並ぶ |

## 前提

法人（株式会社）／決算11月／消費税は来季から課税事業者。
いずれも設定タブの値で、変えれば別の条件でも使える。

## PL表の読み取り方

行はB列のラベル、列は1行目の「◯月」でMATCHして引く。

```
INDEX(PL!$A:$BZ, MATCH(売上ラベル, PL!$B:$B, 0), MATCH(対象月, PL!$1:$1, 0))
```

ラベル名は設定タブで変えられる（`rowSales` / `rowPaid`）。
シート名も空なら「支払い合計」がある表を自動で探す。

## 税額の計算

`corporateTaxFormula_` が年間所得から次を合算する。税率はすべて設定タブの値。

- 法人税 … 800万円以下は軽減税率、超過分は本則
- 地方法人税 … 法人税額 × 率
- 住民税 … 法人税割（法人税額 × 率）＋ 均等割（赤字でもかかる）
- 事業税 … 400万円／800万円で3段階
- 特別法人事業税 … 事業税額 × 率

年間所得は「累計利益 ÷ 実績月数 × 12」で見込む。月が進むほど精度が上がる。
月々の積立は年間見込み ÷ 12。

消費税は簡易課税・第5種（みなし仕入率50%）を想定し、
売上に対する積立率4.5%を既定にしている（税込売上 × 10/110 × 50%）。
区分が違えば設定タブの率を変える。

**すべて資金繰りのための概算であって、申告額そのものではない。**
実際の申告・納付額は顧問税理士に確認する前提で作ってある。

## 資金繰り予測の組み方

- 事業年度の12ヶ月を決算月から並べる（決算11月なら12月始まり）
- 残高は「残高の基準日」の月から積み上げる。それより前の月は空欄
- 基準月は月初残高として扱い、その月の収支も足す（月が飛ばない）
- 納税は決算月+2ヶ月に確定分、+8ヶ月に中間分を置く
- 判定は 残高マイナス→危険 / 安全ライン未満→注意 / それ以外→良好

安全ラインは「実績月の平均支払額 × 安全月数」。

## 作り直しても消えないもの

- 設定タブの入力値（keyで突き合わせて引き継ぐ）
- 支払い予定の支払日・方法・メモ（項目名で突き合わせて引き継ぐ）

PLに項目を足したときは、メニューの「支払い予定の項目をPLから読み直す」で追従する。

## 検証

`SpreadsheetApp` のモック（セルの値を実際に保持する）で通しの実行を確認している。
2回実行してもタブが増えないこと、数式の参照先が正しいことを見ている。
