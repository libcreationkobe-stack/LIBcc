# 月次請求書の自動PDF作成

スプレッドシートに「誰に・何を・いくら」を入れておくと、**毎月きまった日に請求書PDFを自動で作って Drive に保存**します。
（同じGASプロジェクト内の機能です。GBPの投稿ツールとは独立して使えます）

レイアウト・自社情報・振込先は、実際に発行されている請求書（例:「6月分請求書:チームゼロ株式会社様.pdf」）に合わせて初期設定してあります。

## 全体フロー

```
  ┌──── 請求先マスタ ────┐   ┌──── 請求明細 ────┐
  │ 会社名・住所・支払期日 │   │ 対象年月・品目・単価 │
  └──────────┬─────────┘   └────────┬─────────┘
             └──────────┬───────────┘
                        ▼  毎月25日 8時（自動）／メニューから手動
             ┌────────────────────────┐
             │ 対象年月 × 請求先ID でまとめる │
             │ → 税率ごとに消費税を計算       │
             │ → HTMLレイアウト → PDF変換    │
             └───────────┬────────────┘
                         ▼
     Drive「請求書PDF / 2026年8月 / 8月分請求書:〇〇株式会社様.pdf」
                         ▼
              「請求書ログ」シートに1行記録（二重発行を防止）
                         ▼
            （任意）PDFを添付したGmailの下書きを作成
```

## 1. シートを用意する

メニュー **［請求書］→［シートを準備する］** を実行すると、次の3シートが見出し付きで作られます。

### 請求先マスタ（1行＝1社）

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| 請求先ID | 請求先名 | 敬称 | 部署・担当者 | 郵便番号 | 住所 | メールアドレス | 支払期日 | 備考 | 有効 |
| C001 | チームゼロ株式会社 | 御中 | | 780-8035 | 高知県高知市河ノ瀬町144番地 森ビル3階東 | | 当月末 | | TRUE |

- **請求先ID**: 請求明細と紐付けるキー。好きな文字列でOK（`C001` など）
- **支払期日**: `当月末`（既定） / `翌月末` / `翌々月末` / `翌月20日` / `30`（対象月末から30日後）
- **有効**: `FALSE` や `無効` にするとその請求先は作成対象から外れます（空欄は有効）

### 請求明細（1行＝1明細）

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| 対象年月 | 請求先ID | 品目 | 数量 | 単位 | 単価(税抜) | 税率(%) | 備考 |
| 2026-08 | C001 | ひなとりインスタ運用 ベーシック(8月分) | 1 | | 50000 | | |
| 2026-08 | C001 | 蔵木MEO(8月分) | 1 | | 15000 | | |
| 2026-08 | C001 | 紹介割 | 1 | | -20000 | | |

- **対象年月**: `2026-08` / `2026/8` / `2026年8月` / 日付セル のいずれでもOK
- 同じ〈対象年月 × 請求先ID〉の行が、**1枚の請求書にまとまります**
- **単価にマイナスを入れると値引き行**になります（PDFでは `(20,000)` と表示されます）
- **税率**: 空欄なら10%。軽減税率は `8` を入れると税率列と「※」の注記が自動で付きます
- **単位**: 空欄でOK（入れると数量の横に「2.5 時間」のように表示されます）
- 毎月同じ内容なら、前月の行をコピーして対象年月と品目の「(〇月分)」を書き換えるのが手軽です

### 請求書ログ（自動入力）

発行日時 / 対象年月 / 請求先ID / 請求先名 / 請求書番号 / 小計 / 消費税 / 合計 / PDFのURL / ステータス

**このログを見て二重発行を防いでいます**（同じ請求書番号があればスキップ）。手で消さないでください。

## 2. 保存先フォルダの設定

`gas/InvoiceConfig.gs` の次の2つで、PDFの置き場所が決まります。

```js
PDF_PARENT_FOLDER: '',            // 毎月のフォルダを置く親フォルダ（DriveのURLかID）
MONTH_FOLDER_FORMAT: 'yyyy年M月',  // 月フォルダの名前
```

- **毎月のフォルダを手動で作っている場合**でも大丈夫です。`MONTH_FOLDER_FORMAT` を実際のフォルダ名の付け方に合わせておけば、
  **同じ名前のフォルダがあればそこに保存**し、無ければ自動で作ります（作り忘れても止まりません）。
  - 例: `2026年8月` → `'yyyy年M月'` ／ `2026-08` → `'yyyy-MM'` ／ `2026年8月請求書` → `'yyyy年M月請求書'`
- `PDF_PARENT_FOLDER` は、**月フォルダを入れている親フォルダのURLをそのまま貼る**だけでOKです。
  （例: `https://drive.google.com/drive/folders/1AbCdEf...`）
  空欄の場合はマイドライブ直下に「請求書PDF」フォルダを作り、その中に月フォルダを作ります。
- ファイル名は `PDF_NAME_TEMPLATE`（既定: `{M}月分請求書:{請求先名}様`）。
  `{yyyy}` `{M}` `{MM}` `{yyyyMM}` `{請求先名}` `{請求書番号}` が使えます。

## 3. 自社情報・発行サイクルの設定

`gas/InvoiceConfig.gs` の `INVOICE_CONFIG.ISSUER` に自社情報が入っています（住所・電話・振込先は設定済み）。

```js
ISSUER: {
  NAME: '株式会社LIB creation.',
  REGISTRATION_NO: '',   // ← インボイスの登録番号（T+13桁）を入れると請求書に印字されます
  ...
}
```

> **登録番号（T+13桁）だけ空欄です。** 入れておくと適格請求書（インボイス）の要件を満たした形で印字されます。

あわせて調整できる主な設定：

| 設定 | 既定値 | 内容 |
|------|--------|------|
| `TARGET_MONTH_OFFSET` | `0` | 自動実行時の対象月（0＝実行した月ぶん、-1＝前月ぶん） |
| `TRIGGER_DAY_OF_MONTH` / `TRIGGER_HOUR` | `25` / `8` | 毎月何日の何時に自動作成するか |
| `DEFAULT_DUE_RULE` | `'当月末'` | 支払期日が空欄のときのルール |
| `TAX_ROUNDING` | `'floor'` | 消費税の端数処理（`floor`／`round`／`ceil`） |
| `DEFAULT_TAX_RATE` | `10` | 税率が空欄のときの税率 |
| `INVOICE_NO_PREFIX` / `INVOICE_NO_LABEL` | `'INV'` / `'請求書番号'` | 番号の形（`INV-202608-C001`）と、PDFでの見出し（`伝票番号` などに変更可） |
| `FOOTER_NOTE` | 振込手数料の一文 | 備考欄に入れる文言（改行は `\n`） |
| `CREATE_GMAIL_DRAFT` | `false` | `true` でGmailの**下書き**も作成（送信はしません） |

請求書の見た目（項目の並び・罫線・文字サイズ）は `gas/InvoiceTemplate.gs` のHTML/CSSを編集してください。
PDF変換は簡易なHTMLレンダラーを使うため、Webフォントや複雑なCSSは反映されません。

## 4. 手動で作ってみる

メニュー **［請求書］** から実行できます。

| メニュー | 内容 |
|----------|------|
| 請求書PDFを作成（2026-09ぶん） | 既定の対象月ぶんをまとめて作成（見出しに対象月が出ます） |
| 対象年月を指定して作成… | `2026-08` のように月を指定して作成 |
| 作り直す（発行済みも上書き）… | 金額を直したときなどに、同じ請求書番号で作り直し |
| 毎月の自動作成をON／OFFにする | 時間主導トリガーの設定・解除 |
| シートを準備する | 3シートの作成と見出しの整備 |

実行後、結果（作成／スキップ／エラーの件数と内訳）と保存先がダイアログで表示されます。

## 5. 毎月の自動作成をONにする

メニュー **［請求書］→［毎月の自動作成をONにする］** を1回実行すれば設定完了です。
毎月25日の8時ごろに、その月ぶんの請求書PDFが自動で作られます（初回のみ権限の承認が必要です）。

- 自動実行の結果は Apps Script エディタの「実行数」ログで確認できます
- **すでに発行済みの請求書は作り直されません**（請求書ログでチェック）
- 25日までに「請求明細」に行が入っていないと、その請求先は作成されません

## 6. メールで送りたい場合（任意）

`INVOICE_CONFIG.CREATE_GMAIL_DRAFT` を `true` にすると、PDFを添付したGmailの**下書き**が作られます。
自動で送信はしません（宛先や文面を人が確認してから送る運用です）。
この機能を使わない場合は、`gas/appsscript.json` から `gmail.compose` のスコープ行を削除しても構いません。

## よくあるつまずき

| 症状 | 原因・対処 |
|------|-----------|
| 「シート "請求明細" が見つかりません」 | メニュー［請求書］→［シートを準備する］を実行 |
| 何も作成されない | 「請求明細」の**対象年月**が対象の月と一致しているか確認（`2026-8` は `2026-08` として扱われます） |
| 「請求先ID … が請求先マスタにありません」 | 明細のB列と請求先マスタのA列を一致させる |
| 「保存先フォルダが見つかりません」 | `PDF_PARENT_FOLDER` にフォルダのURLを貼り直す（ファイルのURLではなくフォルダのURL） |
| 金額を直したのにPDFが変わらない | 発行済みはスキップされます。［作り直す（発行済みも上書き）］を使ってください |
| PDFの文字が詰まって見える | `InvoiceTemplate.gs` のCSS（`font-size`・`padding`）を調整してください |
