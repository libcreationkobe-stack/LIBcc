# 月次請求書の自動PDF作成

スプレッドシートに「誰に・何を・いくら」を入れておくと、**毎月きまった日に請求書PDFを自動で作って Drive に保存**します。
（同じGASプロジェクト内の機能です。GBPの投稿ツールとは独立して使えます）

## 全体フロー

```
  ┌──── 請求先マスタ ────┐   ┌──── 請求明細 ────┐
  │ 会社名・住所・支払期日 │   │ 対象年月・品目・単価 │
  └──────────┬─────────┘   └────────┬─────────┘
             └──────────┬───────────┘
                        ▼  毎月1日 8時（自動）／メニューから手動
             ┌────────────────────────┐
             │ 対象年月 × 請求先ID でまとめる │
             │ → 税率ごとに消費税を計算       │
             │ → HTMLレイアウト → PDF変換    │
             └───────────┬────────────┘
                         ▼
        Drive「請求書PDF / 2026-08 / 請求書_202608_〇〇.pdf」
                         ▼
              「請求書ログ」シートに1行記録（二重発行を防止）
                         ▼
            （任意）PDFを添付したGmailの下書きを作成
```

## 1. シートを用意する

メニュー **［請求書］→［シートを準備する］** を実行すると、次の3シートが見出し付きで作られます。

### 請求先マスタ（1行＝1社）

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| 請求先ID | 請求先名 | 敬称 | 部署・担当者 | 郵便番号 | 住所 | メールアドレス | 支払期日 | 備考 | 有効 |
| C001 | 株式会社〇〇 | 御中 | 経理部 | 650-0001 | 神戸市中央区… | keiri@example.com | 翌月末 | 月末締め | TRUE |

- **請求先ID**: 請求明細と紐付けるキー。好きな文字列でOK（`C001` など）
- **支払期日**: `翌月末` / `当月末` / `翌々月末` / `翌月20日` / `30`（対象月末から30日後）。空欄なら `翌月末`
- **有効**: `FALSE` や `無効` にするとその請求先は作成対象から外れます（空欄は有効）

### 請求明細（1行＝1明細）

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| 対象年月 | 請求先ID | 品目 | 数量 | 単位 | 単価(税抜) | 税率(%) | 備考 |
| 2026-08 | C001 | サイト運用保守 | 1 | 式 | 50000 | 10 | 定額 |
| 2026-08 | C001 | 撮影・編集 | 2.5 | 時間 | 8000 | 10 | |

- **対象年月**: `2026-08` / `2026/8` / `2026年8月` / 日付セル のいずれでもOK
- 同じ〈対象年月 × 請求先ID〉の行が、**1枚の請求書にまとまります**
- **税率**: 空欄なら10%。軽減税率は `8` を入れると、請求書に「※」と注記が付きます
- 毎月同じ内容なら、前月の行をコピーして対象年月だけ書き換えるのが手軽です

### 請求書ログ（自動入力）

発行日時 / 対象年月 / 請求先ID / 請求先名 / 請求書番号 / 小計 / 消費税 / 合計 / PDFのURL / ステータス

**このログを見て二重発行を防いでいます**（同じ請求書番号があればスキップ）。手で消さないでください。

## 2. 自社情報を設定する

`gas/InvoiceConfig.gs` の `INVOICE_CONFIG.ISSUER` を自社の情報に書き換えます。

```js
ISSUER: {
  NAME: '株式会社サンプル',
  REGISTRATION_NO: 'T1234567890123',   // 適格請求書（インボイス）の登録番号
  POSTAL_CODE: '650-0001',
  ADDRESS: '兵庫県神戸市中央区〇〇1-2-3',
  TEL: '078-000-0000',
  EMAIL: 'info@example.com',
  BANK: 'サンプル銀行 神戸支店 普通 1234567 カ）サンプル'
}
```

あわせて調整できる主な設定：

| 設定 | 既定値 | 内容 |
|------|--------|------|
| `TARGET_MONTH_OFFSET` | `-1` | 自動実行時の対象月（-1＝前月ぶん） |
| `TRIGGER_DAY_OF_MONTH` / `TRIGGER_HOUR` | `1` / `8` | 毎月何日の何時に自動作成するか |
| `TAX_ROUNDING` | `'floor'` | 消費税の端数処理（`floor`／`round`／`ceil`） |
| `DEFAULT_TAX_RATE` | `10` | 税率が空欄のときの税率 |
| `INVOICE_NO_PREFIX` | `'INV'` | 請求書番号の接頭辞（`INV-202608-C001`） |
| `PDF_FOLDER_NAME` | `'請求書PDF'` | PDFの保存先フォルダ名 |
| `CREATE_GMAIL_DRAFT` | `false` | `true` でGmailの**下書き**も作成（送信はしません） |

請求書の見た目（レイアウト・項目の並び）は `gas/InvoiceTemplate.gs` のHTML/CSSを編集してください。
PDF変換は簡易なHTMLレンダラーを使うため、Webフォントや複雑なCSSは反映されません。

## 3. 手動で作ってみる

メニュー **［請求書］** から実行できます。

| メニュー | 内容 |
|----------|------|
| 請求書PDFを作成（前月ぶん） | 既定の対象月（前月）ぶんをまとめて作成 |
| 対象年月を指定して作成… | `2026-08` のように月を指定して作成 |
| 作り直す（発行済みも上書き）… | 金額を直したときなどに、同じ請求書番号で作り直し |
| 毎月の自動作成をON／OFFにする | 時間主導トリガーの設定・解除 |
| シートを準備する | 3シートの作成と見出しの整備 |

実行後、結果（作成／スキップ／エラーの件数と内訳）がダイアログで表示されます。
PDFは Drive の **「請求書PDF / <対象年月>」** フォルダに入ります。

## 4. 毎月の自動作成をONにする

メニュー **［請求書］→［毎月の自動作成をONにする］** を1回実行すれば設定完了です。
毎月1日の8時ごろに前月ぶんの請求書PDFが自動で作られます（初回のみ権限の承認が必要です）。

- 自動実行の結果は Apps Script エディタの「実行数」ログで確認できます
- **すでに発行済みの請求書は作り直されません**（請求書ログでチェック）
- 実行日までに「請求明細」に行が入っていないと、その請求先は作成されません

## 5. メールで送りたい場合（任意）

`INVOICE_CONFIG.CREATE_GMAIL_DRAFT` を `true` にすると、PDFを添付したGmailの**下書き**が作られます。
自動で送信はしません（宛先や文面を人が確認してから送る運用です）。
この機能を使わない場合は、`gas/appsscript.json` から `gmail.compose` のスコープ行を削除しても構いません。

## よくあるつまずき

| 症状 | 原因・対処 |
|------|-----------|
| 「シート "請求明細" が見つかりません」 | メニュー［請求書］→［シートを準備する］を実行 |
| 何も作成されない | 「請求明細」の**対象年月**が対象の月と一致しているか確認（`2026-8` は `2026-08` として扱われます） |
| 「請求先ID … が請求先マスタにありません」 | 明細のB列と請求先マスタのA列を一致させる |
| 金額を直したのにPDFが変わらない | 発行済みはスキップされます。［作り直す（発行済みも上書き）］を使ってください |
| PDFの文字が詰まって見える | `InvoiceTemplate.gs` のCSS（`font-size`・`padding`）を調整してください |
